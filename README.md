# Parakh Inspector Aid

Build a premium, production-quality frontend prototype called:

PARAKH AI

AI-Assisted Legal Metrology Inspection Intelligence Platform

IMPORTANT:

This is a FRONTEND-ONLY prototype for a hackathon jury demonstration.

DO NOT build a backend.

DO NOT create authentication APIs.

DO NOT create a real database.

DO NOT integrate real government systems.

DO NOT require API keys.

Everything must work using realistic mock data, local state, seeded datasets, and simulated processing.

The prototype must feel like a REAL government inspection platform, not an AI-generated template.
